# WordPress 101 for Content Creators — Glossary

Plain-language definitions of terms used in the course. The lesson that introduces each term is in brackets.

- **Custom domain** — a web address you own and pay for (e.g. `yourname.com`), instead of a platform's subdomain like `yourname.substack.com`. Links and search rankings build up on it. [M01.L01]
- **Owned vs rented audience** — readers you can reach directly and take with you (your email list, your domain) vs followers who exist only inside a platform and can be lost when its rules or algorithm change. [M01.L01]
- **Revenue share** — a percentage of your income a platform keeps (e.g. 10% of paid subscriptions), as opposed to a fixed monthly fee. [M01.L01]
- **Self-hosted WordPress (WordPress.org)** — the free, open-source WordPress software installed on a web host you choose and pay for, giving you full control over plugins, design, data and domain. [M01.L01]
- **WordPress.com** — a hosted service run by Automattic that runs WordPress for you. Its plans decide which features (such as plugins) you can use. [M01.L01]
- **WordPress Playground** — a free version of WordPress that runs entirely in your web browser, for practice and testing. It isn't a public website. [M01.L01]
- **WXR export file** — the `.xml` file created by WordPress's **Tools → Export**, containing your posts, pages, comments, categories and tags so you can import them into another WordPress site. Media files are referenced, not included. [M01.L01]
