# WordPress 101 for Content Creators — Glossary

Plain-language definitions of terms used in the course. The lesson that introduces each term is in brackets.

- **301 redirect** — an HTTP response meaning *moved permanently*; browsers go to the new URL and Google shows it in results and passes the old URL's signals to it. Use 302/307 only for temporary moves. [M05.L02]
- **3-2-1 rule** — keep 3 copies of your data, on 2 different kinds of storage, with 1 off-site. [M01.L05]
- **A / AAAA record** — a DNS record that points a name to a server's IPv4 (A) or IPv6 (AAAA) address. [M01.L02]
- **Accessibility overlay** — a third-party widget or script that promises one-click accessibility compliance; it doesn't fix the site's underlying problems and many disabled users find it gets in the way. [M04.L05]
- **Accessibility-ready tag** — a WordPress.org theme tag given after manual review against the Themes Team's minimum accessibility requirements; not a WCAG AA guarantee. [M04.L01]
- **Adaptive streaming** — video services send smaller or larger versions to suit each viewer's connection and screen; a self-hosted file is one fixed size. [M03.L05]
- **AI Overviews and AI Mode** — Google Search's AI-generated answers with supporting links; pages must be indexed and snippet-eligible, with no extra requirements. Traffic counts in Search Console's Performance report. [M05.L01]
- **Alt text (alternative text)** — the image's `alt` attribute, read by screen readers and shown if the image fails; describes its purpose in that post in one short sentence. [M03.L03]
- **Anchor text** — the clickable words of a link; should describe the target page (not "click here"). [M05.L03]
- **Answer-first paragraph** — an opening (or section start) whose first 2–3 sentences give the direct answer or promise before any story; easy for readers and AI answers to use. [M05.L03]
- **Archive page (category / tag)** — the page WordPress builds automatically for each category or tag, listing its posts, e.g. `/category/recipes/` or `/tag/paneer/`. [M02.L03]
- **Aspect ratio** — an image's shape as width to height (e.g. 3:2, 16:9, 1.91:1); themes and platforms crop images to a fixed ratio. [M03.L04]
- **Attachment** — WordPress's name for any file in the Media Library, with its own details (alt text, caption, description, file URL). [M03.L01]
- **Autosave** — a temporary copy of a post WordPress saves about every 60 seconds while you type; there's one per user per post, replaced each time. [M02.L04]
- **AVIF** — a modern image format with very small files, supported in current browsers and in WordPress since 6.5; keep a JPEG/PNG fallback for older tools. [M03.L02]
- **Backup (database + files)** — a copy of your site's database (posts, pages, settings, users) and files (themes, plugins, uploads); a restore needs both. [M01.L05]
- **Backup codes** — single-use codes generated when you set up 2FA, used to log in if you lose your phone or key; save them in your password manager. [M01.L05]
- **Bandwidth** — the data your host sends to visitors; many plans limit it, and self-hosted video uses it fast. [M03.L05]
- **Big image threshold (-scaled)** — images wider or taller than 2560 px get a "-scaled" copy (max 2560 px) used as the full size; the original is kept. [M03.L01]
- **Bing Webmaster Tools** — Microsoft's free dashboard for Bing (and Copilot) visibility: verification, sitemaps, URL Inspection, IndexNow and the AI Performance report; can import sites from Search Console. [M05.L05]
- **Block** — a single unit of content in the WordPress editor (paragraph, heading, image, list, quote, button…) that you can move, style and transform. [M02.L01]
- **Block theme** — a theme built entirely from blocks and theme.json, edited visually in the Site Editor (Appearance → Editor); tagged Full Site Editing. [M04.L01]
- **Block toolbar** — the small bar above the selected block with its type, alignment, formatting and Options menu; reach it from the keyboard with Alt+F10. [M02.L01]
- **Breadcrumbs (BreadcrumbList)** — a trail such as Home / Blog / Recipes / Post showing where a page sits; WordPress 7.0 has a core Breadcrumbs block, and SEO plugins add BreadcrumbList schema. [M05.L02]
- **Call to action (CTA)** — a short prompt asking the reader to do one thing next, such as "Subscribe" or "Download the guide", usually with a button. [M02.L02]
- **CAPTCHA** — a test that tells people from bots before a form is sent, such as Cloudflare Turnstile, hCaptcha or reCAPTCHA; it blocks more spam but adds a third-party service. [M04.L04]
- **Captions (video)** — on-screen text of the speech plus important sounds; required by WCAG for prerecorded video with sound. [M03.L03]
- **Category** — a hierarchical way to group posts into the main sections of your site; every post has at least one. [M02.L03]
- **Classic theme** — a PHP-template theme customised in the Customizer, with separate Menus and Widgets screens. [M04.L01]
- **Closed plugin** — a plugin removed from the WordPress.org directory ("This plugin has been closed as of … Reason: …"), often for a security issue; it gets no updates there, so replace it. [M06.L01]
- **CNAME record** — a DNS record that points one name to another name, e.g. `www` → your main domain. [M01.L02]
- **Command palette** — a search box opened with Ctrl+K / ⌘+K anywhere in the WordPress dashboard to jump to any screen or tool by name. [M01.L03]
- **Contact form** — fields (name, email, message) that email the message to you and, in most form plugins, store it in WordPress, without showing your email address. [M04.L04]
- **Content pillar** — one of the 4–7 big themes your site is about; each pillar usually becomes a category. [M02.L03]
- **Content width** — how wide your theme displays a normal block in a post (e.g. 645 px in Twenty Twenty-Five, with 1340 px for wide blocks). [M03.L01]
- **Contrast ratio** — how different a text colour is from its background, from 1:1 (none) to 21:1 (black on white). WCAG 2.2 AA needs at least 4.5:1 for normal text and 3:1 for large text. [M04.L02]
- **Crawling** — search engines' automated programs (crawlers or bots, e.g. Googlebot, Bingbot) discovering and downloading pages, mostly by following links and sitemaps. [M05.L01]
- **Custom domain** — a web address you own and pay for (e.g. `yourname.com`), instead of a platform's subdomain like `yourname.substack.com`. Links and search rankings build up on it. [M01.L01]
- **Custom HTML block** — a block for pasting embed code a service gives you (e.g. a newsletter form); on a single site only Administrators and Editors can save such code. [M02.L05]
- **Dashboard (WP Admin)** — the admin area at `yoursite.com/wp-admin/` where you manage content, design, plugins, users and settings. [M01.L03]
- **Decorative image (empty alt)** — an image that adds no information; give it `alt=""` so screen readers skip it (not the same as missing alt). [M03.L03]
- **Default category** — the category a post gets when you don't choose one (Uncategorized on a new site); it can't be deleted, only renamed or replaced in Settings → Writing. [M02.L03]
- **Detach** — turns a copy of a synced pattern back into ordinary blocks; that copy stops receiving updates from the original. [M02.L02]
- **Device mode** — the browser developer-tools view (Chrome: Toggle device toolbar) that simulates phone and tablet screen sizes; an approximation, not a real phone. [M04.L05]
- **DNS (Domain Name System)** — the global directory that turns domain names into server addresses. [M01.L02]
- **Domain name** — a human-readable web address such as `priyacooks.com`, rented yearly from a registrar. [M01.L02]
- **Embed** — content from another site (a video, podcast episode or social post) shown inside your post; usually created by pasting a supported link on its own line. [M02.L05]
- **Empty link** — a link with no text a screen reader can announce, such as a linked image without alt text or an icon with no label. [M04.L05]
- **Facade** — a lightweight preview (thumbnail + play button) shown instead of an embedded player, which loads only when clicked. [M03.L05]
- **Fallback image** — a JPEG or PNG copy kept alongside a WebP/AVIF file for browsers, email tools or social sites that can't read the modern format. [M03.L02]
- **Featured image** — a post's main image, set in the editor's Featured image panel; the theme shows it on the post and in archives, and SEO plugins use it for link previews. [M03.L04]
- **Focus indicator** — the visible outline that shows which link, button or field the keyboard is on; WCAG 2.4.7 requires it to be visible. [M04.L05]
- **Font Library** — the **Manage fonts** screen in Styles → Typography, with Library, Upload and Install Fonts tabs; installed fonts are stored on your own site (`wp-content/uploads/fonts`). [M04.L02]
- **Functional image** — an image that is a link or button; its alt says where it goes or what it does. [M03.L03]
- **Global styles** — site-wide design settings in the Site Editor's **Styles** (colours, typography, layout, per-block styles), saved on top of the theme's theme.json. [M04.L02]
- **Grounding (AI citations)** — when an AI answer engine retrieves pages from a search index and cites them as sources for its answer. No index, no citation. [M05.L01]
- **Honeypot** — a hidden form field that people never see but bots fill in, so those submissions are blocked. [M04.L04]
- **HTTPS / TLS certificate** — a certificate that proves your site's identity and encrypts traffic between readers and your site, shown as a padlock in the browser. [M01.L03]
- **Hybrid theme** — a classic theme that supports some block features (e.g. patterns, theme.json) but not full template editing. [M04.L01]
- **Image sizes (thumbnail, medium, large)** — the smaller copies WordPress makes from every upload: 150×150 cropped thumbnail, 300 medium, 768, 1024 large, 1536 and 2048, plus any theme sizes. [M03.L01]
- **Image-optimisation plugin** — a plugin that compresses and/or converts images on upload (e.g. Modern Image Formats, ShortPixel, EWWW); run only one. [M03.L02]
- **Indexing** — a search engine analysing a crawled page and storing it in its index (database); only indexed pages can appear in results or AI answers. [M05.L01]
- **Internal link** — a link from one page on your site to another; helps readers and crawlers find related posts and see which matter. [M05.L03]
- **JSON-LD** — the format Google recommends for structured data: a `<script type="application/ld+json">` block in the page that readers don't see. [M05.L04]
- **Lazy loading** — delaying images or iframes until the reader scrolls near them; WordPress adds `loading="lazy"` automatically except for the first three in the content. [M03.L05]
- **Least privilege** — giving each person only the access their job needs, e.g. Author instead of Administrator. [M01.L05]
- **Let's Encrypt** — a free, non-profit certificate authority whose certificates most hosts issue and renew automatically. [M01.L03]
- **List view** — an outline of every block in a post or page, used to jump around and reorder; toggle with Shift+Alt+O. [M02.L01]
- **Live Preview** — previews an installed theme with your real content before activating it; block themes open in the Site Editor. [M04.L01]
- **Local** — a free app (localwp.com) that runs WordPress sites on your own computer, used for this course's practice site. [M01.L03]
- **Lossless compression** — shrinking a file without changing any pixels (PNG, lossless WebP/AVIF). [M03.L02]
- **Lossy compression** — shrinking a file by discarding detail the eye is unlikely to notice, controlled by a quality setting (JPEG, WebP, AVIF). [M03.L02]
- **Mailpit** — the tool in Local that catches emails your practice site sends, so you can read them without sending real mail (Tools → Mailpit → Open Mailpit). [M04.L04]
- **Managed WordPress hosting** — hosting that adds WordPress-specific updates, backups, caching, security and support on top of the server. [M01.L02]
- **Media kit** — a page or one-page PDF for brands: your audience, dated reach numbers, offers and rates, past partners and how to enquire. [M04.L04]
- **Media Library** — Media → Library, where every uploaded file lives and can be searched, edited and inserted into posts. [M03.L01]
- **Meta description** — a short page summary in the head (`<meta name="description">`); Google may use it for the snippet when it describes the page better than the content. [M05.L02]
- **Missed schedule** — the status WordPress shows when a scheduled post didn't publish on time, usually because WP-Cron didn't run. [M02.L04]
- **Mixed content** — an HTTPS page that still loads some images or scripts over `http://`, which makes browsers show a security warning. [M01.L03]
- **MX record** — a DNS record that says which server receives email for your domain. [M01.L02]
- **Nameservers** — the servers that hold your domain's DNS records; your registrar settings say which ones your domain uses. [M01.L02]
- **Navigation block** — the block that shows a menu; its menus are saved separately (Appearance → Editor → Navigation) and can be reused in the header, footer or mobile overlay. [M04.L03]
- **Navigation fallback** — what a Navigation block shows when it isn't set to a menu: your most recently published menu; if none exists, an imported classic menu or a Page List of all published pages. [M04.L03]
- **noindex** — a robots directive (meta tag or header) telling search engines not to include a page in their index; WordPress adds it site-wide when Discourage search engines is ticked. [M05.L01]
- **Notes (editor)** — comments attached to blocks inside the editor (WordPress 6.9+), for feedback such as "check this link"; readers never see them. [M02.L04]
- **Nulled plugin** — a pirated copy of a premium plugin from an unofficial site; a common source of malware, with no updates. Never use one. [M06.L01]
- **oEmbed (provider)** — the standard WordPress uses to ask a site like YouTube how to display a link; core has a built-in list of trusted providers. [M02.L05]
- **Off-site backup** — a backup stored with a different company from your host (e.g. Google Drive, Dropbox), so it survives if the server fails. [M01.L05]
- **Open Graph (OG) tags** — `og:` meta tags in a page's head (og:title, og:description, og:image, og:url) that platforms read to build link previews; added by an SEO plugin, not core. [M03.L04]
- **Orphan post** — a published post that no other post or page links to in its content (only archives, which push it back over time), so readers and crawlers struggle to find it. [M05.L03]
- **Overlay menu** — the menu button (☰) that opens the menu full-screen; the Navigation block's Overlay Visibility is Mobile by default. [M04.L03]
- **Overrides (synced patterns)** — an option that lets chosen Paragraph, Heading, Image or Button blocks inside a synced pattern hold different content in each copy, while the design stays synced. [M02.L02]
- **Owned vs rented audience** — readers you can reach directly and take with you (your email list, your domain) vs followers who exist only inside a platform and can be lost when its rules or algorithm change. [M01.L01]
- **Page** — permanent, undated content found from menus and links (About, Contact, Start Here); not in the feed and no categories or tags. [M02.L01]
- **Page weight** — the total size of everything a page downloads, shown as "transferred" in the browser's Network panel. [M02.L05]
- **Pages report (page indexing)** — Search Console's report of Indexed vs Not indexed URLs, grouped by reason; many reasons (redirects, noindex, duplicates) are expected. Formerly "Coverage". [M05.L05]
- **Passkey** — a phishing-resistant login credential stored on your device or security key (Touch ID, Windows Hello, YubiKey), usable as a second factor. [M01.L05]
- **Password manager** — an app that generates, stores and fills long, unique passwords (e.g. Bitwarden, 1Password, your browser's or phone's built-in one). [M01.L05]
- **Pattern** — a saved group of blocks (e.g. heading, paragraph and button) you can insert in one go; themes and plugins ship them and you can make your own. [M02.L02]
- **Permalink** — the permanent web address of a post or page, e.g. `https://priyacooks.com/easy-paella/`. [M01.L04]
- **Permalink structure** — the URL pattern WordPress uses for every post, set in Settings → Permalinks (e.g. Post name: `/%postname%/`). [M01.L04]
- **Pingbacks and trackbacks** — automatic notices between blogs when one links to another; today mostly used for spam, so usually turned off. [M01.L04]
- **Plugin bloat** — extra weight a plugin adds: files loaded on pages that don't use it, admin banners, features you don't need. [M06.L01]
- **Plugin log** — your record of every installed plugin: job, why chosen (score), version, install date, source, auto-updates, last review and exit plan. [M06.L01]
- **Podcast host** — a service that stores episodes, creates the podcast RSS feed, distributes it to podcast apps and reports downloads. [M03.L05]
- **Post** — dated content in your publishing stream; appears in the blog index, RSS feed and archives, and uses categories and tags. [M02.L01]
- **Post status** — where a post is in its life: Draft (not ready), Pending (waiting for review), Scheduled (goes live at a set time), Published (visible to everyone) or Private (admins and editors only). [M02.L04]
- **Posts page (blog index)** — the page chosen as Posts page in Settings → Reading; WordPress lists your latest posts there with the Blog Home template and ignores the page's own content. [M04.L03]
- **Pre-publish checklist** — the same short list of checks (title, slug, excerpt, category, featured image, links, preview) run before every post goes live. [M02.L04]
- **Privacy Enhanced Mode (YouTube)** — a YouTube player served from youtube-nocookie.com; views aren't used to personalise the viewer's YouTube experience or ads, but it still loads from Google. [M02.L05]
- **Ranking (serving)** — choosing and ordering the most relevant, helpful indexed pages for a search; Google doesn't guarantee any page will be shown. [M05.L01]
- **Redirect chain** — one redirect leading to another (/a/ → /b/ → /c/); slower and riskier than one hop, and a loop if it leads back. Point old URLs straight at the final one. [M05.L02]
- **Reflow** — WCAG 1.4.10: content works at 320 CSS pixels wide (a phone, or 400% zoom) without scrolling sideways. [M04.L05]
- **Registrar** — a company accredited to sell and manage domain names (for `.in`, accredited by NIXI). [M01.L02]
- **Revenue share** — a percentage of your income a platform keeps (e.g. 10% of paid subscriptions), as opposed to a fixed monthly fee. [M01.L01]
- **Revision** — a saved copy of a post's title, content and excerpt, stored each time you save; you can compare and restore them. WordPress keeps all of them by default. [M02.L04]
- **Rich result** — an enhanced search listing (recipe card, video thumbnail, breadcrumbs, review stars) that valid structured data makes a page eligible for; never guaranteed. FAQ and How-to rich results are no longer shown. [M05.L04]
- **Rich Results Test** — Google's free tool (search.google.com/test/rich-results) that shows which Google rich results a URL or pasted code qualifies for, with errors and warnings. [M05.L04]
- **robots.txt** — a file at your site's root telling crawlers which paths they may fetch; WordPress serves a virtual one blocking only /wp-admin/ and listing your sitemap. [M05.L01]
- **RSS feed (full text vs excerpt)** — a machine-readable list of your latest posts at `/feed/`; Settings → Reading chooses whether it carries the full post or a short excerpt. [M01.L04]
- **sameAs** — a schema.org property listing a person's or organisation's profiles elsewhere (social accounts, About page), tying them to one identity. [M05.L04]
- **Schema Markup Validator** — schema.org's free tool (validator.schema.org) that checks all schema.org markup on a page, including types Google doesn't use. [M05.L04]
- **Search Console property** — a site added to Google Search Console: a Domain property (all subdomains and protocols, DNS-verified) or a URL-prefix property (one exact prefix, several verification methods). [M05.L05]
- **Search equity** — the trust and ranking signals a URL builds up from links, shares and history; it's tied to the exact address. [M01.L04]
- **Search intent** — the job behind a query (Know, Do, Website, Visit-in-person); the top results show which intent, format and angle searchers want. [M05.L03]
- **Self-hosted WordPress (WordPress.org)** — the free, open-source WordPress software installed on a web host you choose and pay for, giving you full control over plugins, design, data and domain. [M01.L01]
- **Self-hosting (media)** — uploading the media file itself to your Media Library so your server streams it to every viewer. [M03.L05]
- **SEO plugin** — a plugin (Yoast SEO, Rank Math, All in One SEO) that controls titles, meta descriptions, robots meta, canonical URLs, Open Graph, schema and the XML sitemap; run only one. [M05.L02]
- **Settings sidebar** — the right-hand editor panel with Post settings (status, categories, featured image, excerpt) and Block settings; toggle with Ctrl+Shift+,. [M02.L01]
- **Sharing debugger** — a tool (Facebook Sharing Debugger, LinkedIn Post Inspector) that shows a platform's link preview for a URL and refreshes its cached copy. [M03.L04]
- **Site Editor** — the block editor for your whole site at **Appearance → Editor** (block themes only), with Navigation, Styles, Pages, Templates and Patterns. [M04.L02]
- **Site verification** — proving to Search Console or Bing that you control a site (DNS TXT record, HTML meta tag, file); checked periodically, so keep it in place. [M05.L05]
- **Slash command** — typing `/` at the start of an empty paragraph to insert any block by name, e.g. `/image`. [M02.L01]
- **Slug** — the post-specific part of a permalink, e.g. `easy-paella`; editable in the post's settings. [M01.L04]
- **Social Icons block** — a row of icon links to your profiles (Bluesky, Instagram, YouTube, TikTok, Mastodon, RSS feed and more). [M04.L03]
- **Social share image (OG image)** — the image in og:image; at least 1200 × 630 px (~1.91:1), JPEG or PNG, text inside a safe central area. [M03.L04]
- **Soft 404** — a URL that returns success or redirects somewhere unhelpful (e.g. the homepage) when the content is really gone; Google may treat it as not found. [M05.L02]
- **srcset and sizes** — image attributes listing the available copies and how wide the image displays, so the browser downloads the smallest copy that looks sharp. [M03.L01]
- **Staging site** — a private copy of your site where you test updates and changes before readers see them. [M01.L02]
- **Start Here page** — a guided tour for new visitors that routes them by goal to a few of your best posts and your newsletter. [M04.L04]
- **Static homepage** — a normal page chosen in Settings → Reading → A static page to be your homepage, instead of a list of your latest posts. [M04.L03]
- **Structured data (schema)** — machine-readable facts about a page using the schema.org vocabulary (Article, Person, VideoObject…); helps understanding and rich-result eligibility, not rankings. [M05.L04]
- **Style variation** — a ready-made alternative look shipped by a block theme, chosen in **Styles → Browse styles**. [M04.L02]
- **Synced pattern** — a pattern whose copies all stay linked: editing the original (Edit original) updates every post and page that uses it. Formerly called a reusable block. [M02.L02]
- **Tag** — an optional, flat label for a specific topic that cuts across categories, e.g. an ingredient, place or series. [M02.L03]
- **Target size** — WCAG 2.5.8 (new in 2.2): tap and click targets at least 24 × 24 CSS pixels, or spaced far enough apart. [M04.L05]
- **Taxonomy** — a way of grouping content; WordPress has two built in for posts: categories and tags. [M02.L03]
- **Template** — the block layout WordPress uses for a type of content, such as Single Posts, Pages, Blog Home or 404. Edits are saved as your own copy and can be reset to the theme's original. [M04.L02]
- **Template hierarchy** — the order WordPress follows to pick a template: the most specific one that exists, falling back to more general ones and finally Index. [M04.L02]
- **Template part** — a reusable block area inside templates, such as the Header or Footer; editing it once updates every template that uses it. [M04.L02]
- **Tested up to** — the newest WordPress version a plugin's developer says they've tested; three or more majors behind triggers a "hasn't been tested" warning in the directory. [M06.L01]
- **theme.json** — the theme settings file defining colours, fonts, spacing and layout widths; it powers Styles in the Site Editor. [M04.L01]
- **Third-party request** — anything your page loads from another company's servers, such as an embed's scripts, images or cookies. [M02.L05]
- **Title template** — an SEO plugin pattern such as *Title – Site name* that builds every post's `<title>`; override it per post only when needed. [M05.L02]
- **Transcript** — a text version of everything said in audio or video, placed on the page; required by WCAG for prerecorded audio-only content. [M03.L03]
- **TTL (time to live)** — how long other computers may cache a DNS record before asking again; why DNS changes take time to show everywhere. [M01.L02]
- **Two-factor authentication (2FA)** — a login that needs your password plus a second proof, such as an authenticator-app code or a passkey. [M01.L05]
- **TXT record** — a DNS record holding text, used for site verification (e.g. Search Console) and email security (SPF, DKIM). [M01.L02]
- **Unsynced pattern** — a pattern inserted as ordinary, independent blocks; a starting template you fill in differently each time. [M02.L02]
- **URL Inspection** — the Search Console tool that shows whether one URL is on Google and why, tests the live page and lets you request indexing. [M05.L01]
- **User role** — a named set of WordPress permissions: Administrator, Editor, Author, Contributor or Subscriber. [M01.L05]
- **WCAG 2.2** — the W3C's Web Content Accessibility Guidelines, version 2.2; Level AA is the usual target and what most accessibility laws refer to. [M04.L05]
- **WebP** — a modern image format supported by all current browsers and by WordPress since 5.8; usually smaller than JPEG for the same quality. [M03.L02]
- **WebVTT (.vtt)** — the caption file format browsers use; upload it to a Video block via Text tracks. [M03.L03]
- **WordPress Address and Site Address** — the two URL settings in Settings → General that tell WordPress its own address; both should start with `https://`. [M01.L03]
- **WordPress Playground** — a free version of WordPress that runs entirely in your web browser, for practice and testing. It isn't a public website. [M01.L01]
- **WordPress.com** — a hosted service run by Automattic that runs WordPress for you. Its plans decide which features (such as plugins) you can use. [M01.L01]
- **WP-Cron** — WordPress's built-in task scheduler; it runs on page loads, so it can be late on sites with few visitors. [M02.L04]
- **WXR export file** — the `.xml` file created by WordPress's **Tools → Export**, containing your posts, pages, comments, categories and tags so you can import them into another WordPress site. Media files are referenced, not included. [M01.L01]
- **XML sitemap** — a machine-readable list of your public URLs for search engines; WordPress core serves one at /wp-sitemap.xml (your SEO plugin may replace it). [M05.L01]
