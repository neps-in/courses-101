# WordPress 101 for Content Creators — Glossary

Plain-language definitions of terms used in the course. The lesson that introduces each term is in brackets.

- **3-2-1 rule** — keep 3 copies of your data, on 2 different kinds of storage, with 1 off-site. [M01.L05]
- **A / AAAA record** — a DNS record that points a name to a server's IPv4 (A) or IPv6 (AAAA) address. [M01.L02]
- **Backup (database + files)** — a copy of your site's database (posts, pages, settings, users) and files (themes, plugins, uploads); a restore needs both. [M01.L05]
- **Backup codes** — single-use codes generated when you set up 2FA, used to log in if you lose your phone or key; save them in your password manager. [M01.L05]
- **Block** — a single unit of content in the WordPress editor (paragraph, heading, image, list, quote, button…) that you can move, style and transform. [M02.L01]
- **Block toolbar** — the small bar above the selected block with its type, alignment, formatting and Options menu; reach it from the keyboard with Alt+F10. [M02.L01]
- **Call to action (CTA)** — a short prompt asking the reader to do one thing next, such as "Subscribe" or "Download the guide", usually with a button. [M02.L02]
- **CNAME record** — a DNS record that points one name to another name, e.g. `www` → your main domain. [M01.L02]
- **Command palette** — a search box opened with Ctrl+K / ⌘+K anywhere in the WordPress dashboard to jump to any screen or tool by name. [M01.L03]
- **Custom domain** — a web address you own and pay for (e.g. `yourname.com`), instead of a platform's subdomain like `yourname.substack.com`. Links and search rankings build up on it. [M01.L01]
- **Dashboard (WP Admin)** — the admin area at `yoursite.com/wp-admin/` where you manage content, design, plugins, users and settings. [M01.L03]
- **Detach** — turns a copy of a synced pattern back into ordinary blocks; that copy stops receiving updates from the original. [M02.L02]
- **DNS (Domain Name System)** — the global directory that turns domain names into server addresses. [M01.L02]
- **Domain name** — a human-readable web address such as `priyacooks.com`, rented yearly from a registrar. [M01.L02]
- **HTTPS / TLS certificate** — a certificate that proves your site's identity and encrypts traffic between readers and your site, shown as a padlock in the browser. [M01.L03]
- **Least privilege** — giving each person only the access their job needs, e.g. Author instead of Administrator. [M01.L05]
- **Let's Encrypt** — a free, non-profit certificate authority whose certificates most hosts issue and renew automatically. [M01.L03]
- **List view** — an outline of every block in a post or page, used to jump around and reorder; toggle with Shift+Alt+O. [M02.L01]
- **Local** — a free app (localwp.com) that runs WordPress sites on your own computer, used for this course's practice site. [M01.L03]
- **Managed WordPress hosting** — hosting that adds WordPress-specific updates, backups, caching, security and support on top of the server. [M01.L02]
- **Mixed content** — an HTTPS page that still loads some images or scripts over `http://`, which makes browsers show a security warning. [M01.L03]
- **MX record** — a DNS record that says which server receives email for your domain. [M01.L02]
- **Nameservers** — the servers that hold your domain's DNS records; your registrar settings say which ones your domain uses. [M01.L02]
- **Off-site backup** — a backup stored with a different company from your host (e.g. Google Drive, Dropbox), so it survives if the server fails. [M01.L05]
- **Overrides (synced patterns)** — an option that lets chosen Paragraph, Heading, Image or Button blocks inside a synced pattern hold different content in each copy, while the design stays synced. [M02.L02]
- **Owned vs rented audience** — readers you can reach directly and take with you (your email list, your domain) vs followers who exist only inside a platform and can be lost when its rules or algorithm change. [M01.L01]
- **Page** — permanent, undated content found from menus and links (About, Contact, Start Here); not in the feed and no categories or tags. [M02.L01]
- **Passkey** — a phishing-resistant login credential stored on your device or security key (Touch ID, Windows Hello, YubiKey), usable as a second factor. [M01.L05]
- **Password manager** — an app that generates, stores and fills long, unique passwords (e.g. Bitwarden, 1Password, your browser's or phone's built-in one). [M01.L05]
- **Pattern** — a saved group of blocks (e.g. heading, paragraph and button) you can insert in one go; themes and plugins ship them and you can make your own. [M02.L02]
- **Permalink** — the permanent web address of a post or page, e.g. `https://priyacooks.com/easy-paella/`. [M01.L04]
- **Permalink structure** — the URL pattern WordPress uses for every post, set in Settings → Permalinks (e.g. Post name: `/%postname%/`). [M01.L04]
- **Pingbacks and trackbacks** — automatic notices between blogs when one links to another; today mostly used for spam, so usually turned off. [M01.L04]
- **Post** — dated content in your publishing stream; appears in the blog index, RSS feed and archives, and uses categories and tags. [M02.L01]
- **Registrar** — a company accredited to sell and manage domain names (for `.in`, accredited by NIXI). [M01.L02]
- **Revenue share** — a percentage of your income a platform keeps (e.g. 10% of paid subscriptions), as opposed to a fixed monthly fee. [M01.L01]
- **RSS feed (full text vs excerpt)** — a machine-readable list of your latest posts at `/feed/`; Settings → Reading chooses whether it carries the full post or a short excerpt. [M01.L04]
- **Search equity** — the trust and ranking signals a URL builds up from links, shares and history; it's tied to the exact address. [M01.L04]
- **Self-hosted WordPress (WordPress.org)** — the free, open-source WordPress software installed on a web host you choose and pay for, giving you full control over plugins, design, data and domain. [M01.L01]
- **Settings sidebar** — the right-hand editor panel with Post settings (status, categories, featured image, excerpt) and Block settings; toggle with Ctrl+Shift+,. [M02.L01]
- **Slash command** — typing `/` at the start of an empty paragraph to insert any block by name, e.g. `/image`. [M02.L01]
- **Slug** — the post-specific part of a permalink, e.g. `easy-paella`; editable in the post's settings. [M01.L04]
- **Staging site** — a private copy of your site where you test updates and changes before readers see them. [M01.L02]
- **Synced pattern** — a pattern whose copies all stay linked: editing the original (Edit original) updates every post and page that uses it. Formerly called a reusable block. [M02.L02]
- **TTL (time to live)** — how long other computers may cache a DNS record before asking again; why DNS changes take time to show everywhere. [M01.L02]
- **Two-factor authentication (2FA)** — a login that needs your password plus a second proof, such as an authenticator-app code or a passkey. [M01.L05]
- **TXT record** — a DNS record holding text, used for site verification (e.g. Search Console) and email security (SPF, DKIM). [M01.L02]
- **Unsynced pattern** — a pattern inserted as ordinary, independent blocks; a starting template you fill in differently each time. [M02.L02]
- **User role** — a named set of WordPress permissions: Administrator, Editor, Author, Contributor or Subscriber. [M01.L05]
- **WordPress Address and Site Address** — the two URL settings in Settings → General that tell WordPress its own address; both should start with `https://`. [M01.L03]
- **WordPress Playground** — a free version of WordPress that runs entirely in your web browser, for practice and testing. It isn't a public website. [M01.L01]
- **WordPress.com** — a hosted service run by Automattic that runs WordPress for you. Its plans decide which features (such as plugins) you can use. [M01.L01]
- **WXR export file** — the `.xml` file created by WordPress's **Tools → Export**, containing your posts, pages, comments, categories and tags so you can import them into another WordPress site. Media files are referenced, not included. [M01.L01]
