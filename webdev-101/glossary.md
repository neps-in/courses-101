# Web Development 101 — Glossary

Plain-language definitions of terms used in the course. The lesson that introduces each term is in brackets.

- **A record** — a DNS record that points a name to an IPv4 address. [M01.L02]
- **AAAA record** — a DNS record that points a name to an IPv6 address. [M01.L02]
- **Absolute vs relative URL** — absolute includes the scheme and domain (`https://site.example/page`); relative is a path from the current file (`images/beans.jpg`) or the site root (`/pricing`). [M02.L02]
- **Accessibility tree** — the browser's map of a page as assistive technology sees it (roles, names, landmarks); view it in Chrome DevTools → Elements → Accessibility. [M02.L03]
- **Alt text (alternative text)** — the `alt` attribute of an image: a short description of what it adds, the destination if it's the only content of a link, the text if it's an image of text, or empty (`alt=""`) if decorative. [M02.L02]
- **Anchor link (same-page link)** — a link to `#id` that jumps to the element with that `id` on the page; ids are case-sensitive and must be unique. [M02.L02]
- **ARIA (aria-label, aria-labelledby)** — attributes that add accessibility information; `aria-label` gives a name directly, `aria-labelledby` points to the `id` of visible text that names the element. Use native HTML first. [M02.L03]
- **aria-describedby** — links a field to extra hint or error text (by `id`) that screen readers read after the label. [M02.L04]
- **Attribute** — extra information on an element, written `name="value"` inside the start tag, e.g. `href="/subscribe"`, `class="cta"`. [M02.L01]
- **Attribute selector** — a CSS selector that matches elements by an attribute, e.g. `input[type="email"]`; counts like a class for specificity. [M03.L01]
- **autocomplete** — attribute with standard tokens (`email`, `given-name`, `tel`, `postal-code`) that lets browsers autofill fields about the user; required by WCAG 2.2 SC 1.3.5. [M02.L04]
- **Blockquote, figure and figcaption** — `<blockquote>` marks a quotation; `<figure>` groups it (or an image) with a `<figcaption>`, e.g. a testimonial and the customer's name. [M02.L02]
- **Box model** — every element is a box of content, padding (inside the border), border, and margin (transparent space outside); DevTools' Computed tab draws it. [M03.L01]
- **box-sizing: border-box** — makes `width` and `height` include padding and border, so boxes are the size you set; usually applied to every element first. [M03.L01]
- **Browser** — the program (Chrome, Edge, Firefox, Safari, Samsung Internet) that requests web pages and renders them on screen. [M01.L01]
- **Browser engine** — the core inside a browser that turns code into a page: Blink (Chrome, Edge), Gecko (Firefox), WebKit (Safari). Different engines are why pages can look slightly different. [M01.L01]
- **Built-in (constraint) validation** — browser checks triggered by HTML alone: `required`, `type="email"`, `minlength`, `pattern`; the form won't submit until they pass. [M02.L04]
- **Cache** — a saved copy of a file or answer reused to save time (browser cache, CDN cache, DNS cache); why changes sometimes don't show at once. [M01.L03]
- **Canonical URL** — the one official address of a page, set with `<link rel="canonical" href="…">`, so copies with tracking parameters count as the same page. [M02.L05]
- **Cascade** — the rules a browser uses to pick one value when several CSS rules set the same property: importance and origin, then specificity, then source order (later wins). [M03.L01]
- **CDN (content delivery network)** — servers around the world that keep copies of your files so visitors get them from nearby. [M01.L03]
- **Certificate (TLS/SSL certificate)** — a digital ID, issued by a certificate authority (CA), proving a server belongs to a domain; it expires and must be renewed automatically. [M01.L03]
- **Character encoding (UTF-8)** — how text is stored as bytes; `<meta charset="utf-8">` plus saving as UTF-8 makes every language and symbol (₹, ₦, é, 中) display correctly. [M02.L01]
- **Class and ID selectors** — `.button` matches every element with `class="button"` (reusable; the default for styling); `#signup` matches the one element with that `id` (very specific; keep for anchors and labels). [M03.L01]
- **Client** — the device and software that asks for something; on the Web, usually your browser. [M01.L01]
- **CMS (content management system)** — software that lets people create and edit content in a browser while the system builds the pages; WordPress is the most common. [M01.L04]
- **CNAME record** — a DNS record that makes one name an alias of another name (e.g. `www` → `yourname.github.io`). [M01.L02]
- **Computed tab** — the DevTools Elements tab that shows the final value of every CSS property for the selected element, plus its box-model diagram. [M03.L01]
- **Consent (affirmative)** — permission the visitor gives by a clear action, such as ticking an unticked box; pre-ticked boxes or silence don't count (GDPR Recital 32). [M02.L04]
- **Console** — the DevTools panel where the browser reports errors and where you can run JavaScript (Lesson 5.1). [M01.L05]
- **CSS** — the language that controls how a page looks: colours, fonts, spacing, layout. Taught in Module 3. [M01.L01]
- **CSS rule** — a selector plus a block of declarations, `selector { property: value; }`; each declaration sets one property, e.g. `color: #1f2933;`. [M03.L01]
- **Data minimisation** — collecting only the personal data you need for the stated purpose (GDPR Art. 5(1)(c)); fewer fields also means more sign-ups. [M02.L04]
- **Data URL** — an address that contains the content itself, e.g. `data:text/html,<h1>Hi</h1>`; the browser renders it without contacting any server. [M01.L01]
- **Database** — an organised store of content and data (posts, products, users) that a dynamic site reads and writes. [M01.L04]
- **Descendant selector** — two selectors separated by a space, e.g. `footer a`, matching the second when it is anywhere inside the first. [M03.L01]
- **details / summary** — native HTML for an open/close block: `<details><summary>Question</summary>Answer</details>`; keyboard-accessible with no JavaScript. [M02.L03]
- **Device toolbar** — the DevTools mode (Ctrl+Shift+M / Cmd+Shift+M) that previews a page at phone and tablet sizes. [M01.L05]
- **DevTools (developer tools)** — panels built into desktop browsers for inspecting, editing and measuring pages; open with F12, Ctrl+Shift+I or Cmd+Option+I. [M01.L05]
- **DNS (Domain Name System)** — the Internet's layered directory that turns domain names into IP addresses. [M01.L02]
- **Doctype** — `<!DOCTYPE html>`, the first line of a page; switches the browser to standards mode instead of old "quirks mode". [M02.L01]
- **Document outline algorithm** — an old idea that `<section>` nesting would set heading levels; never implemented and removed from the HTML spec in 2022. Only h1–h6 count. [M02.L03]
- **DOM (Document Object Model)** — the browser's live, in-memory version of a page, built from the HTML and changed by JavaScript and DevTools edits; reload rebuilds it. [M01.L05]
- **Domain name** — the human-friendly, registrable part of an address (e.g. `nilacoffee.example`), rented yearly from a registrar. [M01.L02]
- **Dynamic site** — a site whose server runs code to build each page per request, often from a database (logins, carts, search). [M01.L04]
- **Element** — a start tag, its content and its end tag together, e.g. `<p>Hello</p>`. [M02.L01]
- **Elements panel** — the DevTools panel (Firefox: Inspector) showing the DOM as a tree, with a Styles pane listing the CSS for the selected element. [M01.L05]
- **Favicon** — the small site icon in browser tabs, bookmarks and some search results; added with `<link rel="icon">`. [M02.L05]
- **fieldset / legend** — groups related fields (e.g. radio buttons) under a question that screen readers read with each option. [M02.L04]
- **Focus / focus order** — the element currently receiving keyboard input; Tab moves focus through links, fields and buttons in HTML source order. [M02.L04]
- **Form (action, method)** — `<form>` wraps fields; `action` is where data is sent, `method` is how: GET puts it in the URL, POST sends it in the request body. [M02.L04]
- **Fragment** — the part of a URL after `#`; it jumps to a spot on the page and is never sent to the server. [M01.L02]
- **Framework** — a ready-made developer toolkit for building sites or apps, e.g. Next.js or Astro (Module 8). [M01.L04]
- **Generator meta tag** — `<meta name="generator" content="…">` in a page's HTML; many CMSs use it to name themselves. [M01.L04]
- **Head and body** — `<head>` holds information about the page (charset, viewport, title); `<body>` holds what visitors see. [M02.L01]
- **Headers** — extra facts sent with a request or response, e.g. `content-type`, cache rules, cookies, or the new `location` of a redirect. [M01.L03]
- **Heading outline** — the list of a page's headings by level (h1–h6), like a table of contents; one h1, no skipped levels going down. [M02.L03]
- **Hosting** — renting space on an always-on server so your site can be reached: static, shared, managed or cloud/VPS. [M01.L03]
- **HSTS** — a rule a site sends telling browsers to always use HTTPS for it; the browser then upgrades `http://` itself ("307 Internal Redirect"). [M01.L03]
- **HTML** — the language that gives a page its structure and content: headings, paragraphs, links, images. Taught in Module 2. [M01.L01]
- **HTML comment** — a note in the code that browsers ignore: `<!-- like this -->`. [M02.L01]
- **HTTP method** — the kind of request: `GET` fetches a page or file; `POST` sends data, such as a form. [M01.L03]
- **HTTPS / TLS** — HTTP inside an encrypted TLS connection: privacy, integrity and proof of the server's identity, but not proof the site is honest. [M01.L03]
- **iframe (embed)** — an element that shows another page inside yours, e.g. a YouTube player; always give it a `title`. [M02.L02]
- **!important** — a flag on a CSS declaration (`color: red !important;`) that beats normal rules regardless of specificity; avoid it except to override third-party CSS you can't edit. [M03.L01]
- **Inheritance (CSS)** — text properties such as `color`, `font-family` and `line-height` pass from a parent to its children; box properties such as margin, padding, border and background don't. [M03.L01]
- **Input type** — the `type` of an `<input>` (`text`, `email`, `tel`, `checkbox`, `radio`, `date`…) that sets the phone keyboard and built-in checks. [M02.L04]
- **Internet** — a worldwide network of networks that share data using TCP/IP; the "roads" that the Web, email, calls and games travel on. [M01.L01]
- **IP address** — the numeric address of a device on the Internet; IPv4 (`203.0.113.10`) or IPv6 (`2001:db8::1`). [M01.L02]
- **JavaScript** — the programming language browsers run to make pages interactive. Taught in Module 5. [M01.L01]
- **Label** — visible text tied to a field with `<label for>` matching the field's `id`; clicking it focuses the field and screen readers announce it. [M02.L04]
- **Landmark** — a major page region screen readers can jump to: banner (`header`), navigation (`nav`), main (`main`), region (named `section`), complementary (`aside`), contentinfo (`footer`). [M02.L03]
- **lang attribute** — names the page's language on `<html>` (e.g. `en`, `hi`, `pt-BR`, `sw`) for screen readers, translation and search. [M02.L01]
- **Layout shift** — content jumping as late items (often images) load; prevented by `width` and `height` on images. Measured as CLS in Module 7. [M02.L02]
- **Lazy loading** — `loading="lazy"` delays loading an image or iframe until the visitor scrolls near it; don't use it on the hero image. [M02.L02]
- **Link text** — the clickable words of a link; should name the destination ("See subscription prices"), not "Click here". [M02.L02]
- **Lock-in** — how hard it is to move a site to another platform; low for your own files and WordPress, often high for website builders. [M01.L04]
- **mailto: and tel: links** — links that open the visitor's email app or phone dialler; phone numbers use the international `+` format. [M02.L02]
- **Margin collapse** — when two block boxes are stacked, their vertical margins merge into the larger one instead of adding up. [M03.L01]
- **Meta description** — `<meta name="description" content="…">`, a page summary search engines may show as the snippet; no length limit, but it's truncated, and Google may use page text instead. [M02.L05]
- **Metadata** — information about the page, held in `<head>`: title, description, Open Graph, canonical, favicon. Not shown on the page itself. [M02.L05]
- **Mixed content** — an HTTPS page that loads some files over plain `http://`; browsers block or warn about it. [M01.L03]
- **MX record** — a DNS record saying which mail servers receive email for a domain. [M01.L02]
- **name attribute** — the key a field's value is sent under on submit; fields without a `name` aren't sent. [M02.L04]
- **Nameserver** — the server that holds the official DNS records for a domain. [M01.L02]
- **Nesting** — elements inside elements, like boxes; the last one opened must be the first one closed. [M02.L01]
- **Network panel** — the DevTools panel that logs every request a page makes, with status, type, size and timing. [M01.L05]
- **No-code / website builder** — a hosted service with a visual editor, templates and hosting in one (Wix, Squarespace, Webflow, Framer, Shopify). [M01.L04]
- **NS record** — a DNS record listing a domain's nameservers. [M01.L02]
- **NXDOMAIN** — a DNS answer meaning "no such domain"; shown in Chrome as `DNS_PROBE_FINISHED_NXDOMAIN`. [M01.L02]
- **Open Graph (og: tags)** — `<meta property="og:…">` tags (title, description, image, url, type) that social and chat apps read to build a link preview card. [M02.L05]
- **Page weight (transferred vs resources)** — how much a page downloads: *transferred* is the data sent over the network (often compressed); *resources* is the full uncompressed size. [M01.L05]
- **Path** — the part of a URL after the domain that names a page, e.g. `/subscriptions/monthly`. [M01.L02]
- **Placeholder** — faint sample text inside an empty field that disappears on typing; never a replacement for a label. [M02.L04]
- **Preview cache / re-scrape** — platforms save a link's preview card after the first share; after changes, force a fresh read with the Sharing Debugger (Scrape Again) or Post Inspector. [M02.L05]
- **Privacy-enhanced mode** — YouTube's embed option using `youtube-nocookie.com`; YouTube says such views aren't used to personalise viewers' browsing on YouTube. [M02.L02]
- **Query string** — the part of a URL after `?`, made of `key=value` pairs joined by `&`; UTM tags live here. [M01.L02]
- **RDAP** — the Registration Data Access Protocol; since 28 Jan 2025 the official source of gTLD registration data, replacing WHOIS (use lookup.icann.org). [M01.L02]
- **Redirect** — a 3xx response sending the browser to another URL: 301 permanent, 302/307 temporary. A redirect chain is several redirects in a row. [M01.L03]
- **Registrar / registry** — the registrar sells and renews your domain; the registry runs the whole TLD (e.g. Verisign for `.com`). [M01.L02]
- **rel="sponsored" / "nofollow" / "ugc"** — link hints for search engines: paid or affiliate links, links you don't vouch for, and user-generated links. [M02.L02]
- **rem** — a CSS unit equal to the root font size (usually 16 px); grows when the visitor raises their browser's default text size. [M03.L01]
- **Render** — what a browser does when it turns HTML, CSS and JavaScript into the page you see. [M01.L01]
- **Request / response** — the two halves of every web conversation: the browser asks (method, URL, headers), the server answers (status code, headers, body). [M01.L03]
- **Resolver** — the DNS server (your ISP's, or a public one like 8.8.8.8 or 1.1.1.1) that looks up names on your behalf. [M01.L02]
- **Scheme** — the first part of a URL, before `:`, naming the protocol: `https`, `http`, `mailto`, `data`. [M01.L02]
- **Screen reader** — software that reads a page aloud or to a braille display (Narrator, VoiceOver, NVDA, TalkBack, ChromeVox). [M02.L02]
- **Semantic HTML** — choosing elements for what content *is* (`nav`, `main`, `article`, `h2`) rather than how it looks; `div` carries no meaning. [M02.L03]
- **Semantic sectioning elements** — `header`, `nav`, `main`, `section`, `article`, `aside` and `footer`. [M02.L03]
- **Server / web server** — a computer and its software that answer requests by sending files or data; "web server" can mean the hardware, the software or both. [M01.L01]
- **Share image (og:image)** — the preview card image; a full https URL, ideally 1200×630 (1.91:1), under 8 MB, with key content in the centre. [M02.L05]
- **Sharing Debugger / Post Inspector** — Meta's and LinkedIn's free tools that show how a URL's preview will look, list tag problems and refresh the cached card. [M02.L05]
- **Snippet** — the text under a result's title in search results, built from the meta description or page text. [M02.L05]
- **Specificity** — how precise a selector is, counted as IDs – classes – types (e.g. `#signup a` = 1-0-1, `.button` = 0-1-0); the more specific rule wins a conflict. Hover a selector in DevTools to see it. [M03.L01]
- **Static hosting** — hosting that serves your files exactly as uploaded (GitHub Pages, Netlify, Cloudflare Pages); free tiers, HTTPS and CDN usually included. [M01.L03]
- **Static site** — HTML, CSS, JavaScript and image files served exactly as saved, the same for every visitor. [M01.L04]
- **Status code** — the three-digit result of a request: 2xx success, 3xx redirect, 4xx request problem (404 not found), 5xx server problem (500). [M01.L03]
- **Stylesheet (linked, `<style>`, inline)** — CSS can live in a separate file linked with `<link rel="stylesheet" href="styles.css">` (the default), a `<style>` block in `<head>`, or a `style` attribute on one element (avoid). [M03.L01]
- **Subdomain** — an optional label before the domain, e.g. `shop` in `shop.nilacoffee.example`. [M01.L02]
- **Tag** — a label in angle brackets: start tag `<p>`, end tag `</p>`. [M02.L01]
- **target="_blank" / rel="noopener"** — `target="_blank"` opens a link in a new tab; modern browsers imply `noopener` (the new page can't control yours), and adding `rel="noopener"` covers old browsers. [M02.L02]
- **TCP/IP** — the shared rules that let computers on the Internet split data into packets, address them and deliver them. [M01.L01]
- **Template** — a page layout with gaps that a CMS or dynamic site fills with content from the database. [M01.L04]
- **Title tag / title link** — the `<title>` element shown in tabs and bookmarks; Google's clickable "title link" is usually based on it but may come from headings or `og:title`. [M02.L05]
- **Top-level domain (TLD)** — the last part of a domain: generic (gTLD: `.com`, `.org`, `.shop`) or country-code (ccTLD: `.in`, `.ng`, `.br`). [M01.L02]
- **TTL (time to live)** — how many seconds resolvers may cache a DNS answer; why DNS changes take time to appear. [M01.L02]
- **Twitter/X card** — X's link preview; `<meta name="twitter:card" content="summary_large_image">` asks for a large image, and X falls back to `og:` tags for the rest. [M02.L05]
- **TXT record** — a DNS record holding text, used for ownership verification and email protection (SPF, DKIM, DMARC). [M01.L02]
- **URL** — the full address of one page or file: `scheme://subdomain.domain.TLD/path?query#fragment`. [M01.L02]
- **UTM tags** — `utm_source`, `utm_medium`, `utm_campaign` (and others) added to a link's query string so analytics can tell which campaign brought a visitor. [M01.L02]
- **Validator (W3C Nu HTML Checker)** — a free tool at validator.w3.org/nu that lists HTML errors and warnings with line numbers. [M02.L01]
- **View source** — the browser view of the raw HTML a server sent (Ctrl+U; Mac: Cmd+Option+U in Chrome/Edge, Cmd+U in Firefox; or the `view-source:` prefix). [M01.L04]
- **Viewport meta tag** — `<meta name="viewport" content="width=device-width, initial-scale=1">`; makes phones use their real screen width. [M02.L01]
- **Void element** — an element with no content and no end tag: `img`, `meta`, `link`, `input`, `br`, `hr`. [M02.L01]
- **World Wide Web (the Web)** — a system of linked pages and apps, each with a URL, sent over HTTP(S) and shown in a browser; proposed by Tim Berners-Lee at CERN in 1989. [M01.L01]
