# SEO 101 — Glossary

Plain-language definitions of terms used in the course. The lesson that introduces each term is in brackets.

- **Above the fold** — the part of a page visible without scrolling; images here shouldn't be lazy-loaded. [M04.L04]
- **Accordion** — a page element that opens and closes to show or hide more content; fine for Google if the content is in the HTML. [M02.L09]
- **AI Overview** — an AI-written summary with links that Google shows on some searches; no special markup is needed to appear in one (Module 14). [M01.L05]
- **Algorithmic change** — a ranking shift from Google's automated systems; no message is sent and there's no review to request. [M01.L06]
- **Alt text** — the `alt` attribute of an image: a short text replacement read by screen readers and shown if the image fails to load. Use `alt=""` for decoration. [M02.L05]
- **Anchor text (link text)** — the visible, clickable words of a link; it should be descriptive, concise and clear out of context. [M02.L05]
- **Answer-first opening** — a first paragraph that answers the page's main question straight away, then adds detail (also called the inverted pyramid); a reader habit, not a Google rule. [M04.L02]
- **Archive page** — the page WordPress builds for a category, tag, author or date, listing its posts, such as `/category/brew-guides/`; core lists category and tag archives in use in its sitemap. [M05.L02]
- **`aria-label`** — an attribute that gives an element a name for screen readers, such as `<nav aria-label="Main">`; it isn't shown on the page. [M02.L06]
- **Anonymized query** — a rare search that Search Console leaves out of its tables to protect people's privacy. [M03.L03]
- **Attribute** — extra information about an HTML element, written as `name="value"` in the opening tag, such as `href` on a link. [M02.L03]
- **Attribution (favicon, site name, visible URL, breadcrumb)** — the top line of a search result that shows which site it's from. [M01.L05]
- **Autocomplete prediction** — a search Google predicts as you type, based on real searches and shaped by language, location, trends and your past searches. [M03.L02]
- **Baseline** — a dated record of where a site stands before you change anything, so you can measure what your work changed later. [M01.L03]
- **Bing Webmaster Tools** — Bing's free equivalent of Search Console; can import sites verified in Search Console. [M01.L08]
- **Black hat SEO** — tactics that break search engines' spam policies to trick them or visitors. Industry slang. [M01.L06]
- **`<blockquote>`** — marks an extended quotation; the credit goes in visible text outside it. [M02.L07]
- **Boilerplate title** — one title (or one that changes by a single word) used across many pages, so results can't be told apart; Google may rewrite it. [M04.L01]
- **Border (CSS)** — the line around an element's padding in the box model. [M02.L09]
- **Box model** — the layers of every element: content, padding, border and margin. [M02.L09]
- **Breakpoint** — the screen width where a page's layout changes, set with a media query. [M02.L10]
- **Browser** — the app that requests web pages and displays them, such as Chrome, Edge or Safari. [M02.L01]
- **Byline** — the line naming a page's author, ideally linking to more about them; part of showing "Who" made the content. [M04.L03]
- **Canonical URL** — the one URL Google picks to represent a group of pages with the same or very similar content; the others usually aren't shown. [M01.L04]
- **`<caption>` and `<th>`** — `<caption>` works like a heading for a table; `<th>` marks a header cell, with `scope="col"` or `scope="row"` saying what it heads. [M02.L07]
- **Cascade** — how a browser decides which CSS rule wins when several set the same property on an element. [M02.L08]
- **Category page** — a page listing products or posts of one kind; it should link to every item it holds with real links. [M04.L06]
- **Category (WordPress)** — a main section for posts; every post has at least one, and a new site starts with **Uncategorized**. [M05.L02]
- **CDN (content delivery network)** — a network of servers around the world that keeps copies of your files so visitors get them from somewhere nearby. [M02.L01]
- **Chained links** — several links placed side by side with no words between them; Google advises spacing them out with context. [M04.L05]
- **Channel** — a place or route where people hear about you, such as search, social media, email or a physical shop; SEO works on the search channel. [M01.L01]
- **`<cite>`** — marks the title of a creative work, not a person's name. The `cite` attribute is different: it holds a source's URL and isn't for readers. [M02.L07]
- **Class selector** — a CSS selector such as `.tip` that matches every element with that `class`; the usual choice for styling. [M02.L08]
- **Cloaking** — showing search engines different content from visitors, to manipulate rankings. [M01.L06]
- **Close variants** — near-identical phrases that Keyword Planner can count together in one volume. [M03.L03]
- **CMS (content management system)** — software that lets people create and edit content in a browser while the system builds the pages, such as WordPress; Google's docs also call Wix, Blogger and Shopify a CMS. [M02.L02]
- **Commercial intent** — a search made to compare options before deciding, such as "best coffee subscription". An SEO label, not a Google term. [M03.L01]
- **Content marketing** — attracting your audience with useful articles, videos and guides; it feeds SEO, social and email. [M01.L02]
- **Contextual link** — a link inside a page's main text, with words around it that explain why it's there. [M04.L05]
- **Contrast ratio** — how much text stands out from its background, from 1:1 to 21:1; normal text needs at least 4.5:1. [M02.L09]
- **Conversion** — the main action you want a visitor to take, such as booking, buying or signing up; tracked as a "key event" in GA4. [M01.L01]
- **Core Web Vitals** — Google's metrics for loading (LCP), responsiveness (INP) and visual stability (CLS); used in ranking, but no guarantee of rankings. [M01.L07]
- **Correlation vs cause** — two things appearing together doesn't mean one caused the other, e.g. long pages ranking well. [M01.L07]
- **Crawlable link** — a link search engines can reliably follow: an `<a>` element with an `href` that holds a real address. [M02.L05]
- **Crawler / Googlebot** — a program that fetches web pages for a search engine; Googlebot is Google's (smartphone and desktop types). Also called a bot, robot or spider. [M01.L04]
- **Crawling** — a search engine requesting a page and downloading its content. [M01.L04]
- **CSS (Cascading Style Sheets)** — the language that controls how HTML looks. [M02.L08]
- **Custom-coded site** — a site built by developers with no ready-made admin screens unless someone builds them; no platform limits, but nothing comes built in. [M02.L02]
- **Customer journey (funnel)** — the stages a person moves through: awareness → consideration → decision → loyalty; people search at every stage. [M01.L01]
- **Declaration (CSS)** — one instruction in a CSS rule, made of a property and a value, such as `color: brown;`. [M02.L08]
- **Decorative image** — an image that adds no information to the page; it takes an empty `alt=""`, so screen readers skip it. [M02.L05]
- **Default channel group (GA4)** — the labels GA4 gives each visit by where it came from, such as Organic Search, Paid Search, Organic Social, Email, Referral and Direct. [M01.L02]
- **Device mode** — the DevTools feature that approximates how a page looks and behaves on a phone or tablet. [M02.L10]
- **Digital marketing** — marketing (audience, offer, message) done through online channels such as search, social media, email and websites. [M01.L02]
- **Direct traffic** — visits from a saved link or from typing your address (GA4: Direct). [M01.L02]
- **Discovery** — a search engine learning that a URL exists, mostly from links on known pages and from sitemaps. [M01.L04]
- **`<div>`** — a generic container with no meaning; use it for styling, or when no semantic element fits. [M02.L06]
- **DNS (Domain Name System)** — the internet's address book: it turns a domain name into an IP address. [M02.L01]
- **DNS record (A, AAAA)** — an entry in a domain's DNS settings; an A record points to an IPv4 address and an AAAA record to an IPv6 address. [M02.L01]
- **DNS TXT record** — a line of text in a domain's DNS settings, used to prove control of the domain; a domain can have several. [M01.L08]
- **Doctype** — the first line of a page, `<!DOCTYPE html>`, which tells browsers to use modern HTML rules. [M02.L03]
- **Document Outline** — the block editor's list of a page's headings, in **Document Overview > Outline**, which flags skipped levels, extra H1s and empty headings. [M05.L03]
- **Domain Authority (DA)** — a score made by an SEO tool company, not by Google; a rough comparison at best. [M01.L07]
- **Domain name** — the readable address of a website, such as `nilacoffee.example`; you pay for the right to use it for a set period, and you never own it. [M02.L01]
- **Domain property** — a Search Console property covering all subdomains, protocols and subpaths; verified by a DNS record. [M01.L08]
- **Dominant interpretation** — what most people mean by a search; not every search has one (Google's rater guidelines). [M03.L01]
- **Doorway abuse** — pages made to rank for similar searches that send people to a less useful intermediate page. [M01.L06]
- **E-E-A-T** — experience, expertise, authoritativeness and trustworthiness; qualities Google's systems look for, not a single ranking factor or score. [M01.L07]
- **Earned media** — attention others give you, such as organic rankings, reviews, press and links; it can be encouraged but not honestly bought. [M01.L02]
- **Element (HTML)** — one piece of a page: an opening tag, its content and a closing tag. [M02.L03]
- **`<em>` and `<strong>`** — `<em>` marks stressed words that change a sentence's meaning; `<strong>` marks important, serious or urgent words. For looks alone, use CSS. [M02.L04]
- **Email list** — people who have agreed to get emails from you; an owned channel. [M01.L02]
- **Embed** — content from another site shown inside your page, such as a YouTube video; its words usually aren't in your page's code. [M02.L07]
- **Enhanced measurement** — GA4 events collected with no extra code, such as page views, scrolls and outbound clicks. [M01.L08]
- **External stylesheet** — CSS in a separate `.css` file, linked with `<link rel="stylesheet">`; one file can style many pages. [M02.L08]
- **Fake heading** — a bold or large paragraph made to look like a heading; it isn't in the outline, and screen readers can't jump to it (course term). [M05.L03]
- **Featured snippet** — a box where Google reverses the usual format and shows the answer text first, then the link; can't be requested with markup. [M01.L05]
- **GA4 property** — the container for a site's Google Analytics 4 data. [M01.L08]
- **Google Search Console** — Google's free tool showing how a site performs in Search before the click: searches, clicks and indexing. [M01.L08]
- **Google Trends** — Google's free tool showing relative interest in a search over time and by place, on a 0–100 scale. It doesn't show counts. [M03.L03]
- **Grey hat SEO** — disputed tactics between white and black hat; not a safe zone, as Google has no such category. [M01.L06]
- **`<h1>`** — the top heading level; it should name the page's main topic. HTML allows several, but this course uses one per page. [M02.L04]
- **`<head>` and `<body>`** — the two main parts of a page: the head holds information about the page, and the body holds what people see. [M02.L03]
- **Heading** — an `<h1>` to `<h6>` element that names the section below it; choose the level by structure, not by size. [M02.L04]
- **Heading outline** — a page's headings read in order and indented by level, like a contents list. [M02.L04]
- **Hidden text abuse** — hiding content solely to manipulate search engines, such as white text on a white background; against Google's spam policies. [M02.L09]
- **Hosting** — the service of keeping a website on a server that is always online; the company that provides it is your host. [M02.L01]
- **HTML (HyperText Markup Language)** — the language that labels the parts of a web page, such as headings, paragraphs and links. [M02.L03]
- **HTTP and HTTPS** — the rules browsers and servers use to talk to each other; HTTPS is the encrypted version. [M02.L01]
- **ID selector** — a CSS selector such as `#intro` that matches the one element with that `id`. [M02.L08]
- **`<iframe>`** — an element that shows another document inside your page; give each one a descriptive `title`. [M02.L07]
- **Impression** — in Search Console, a time your site appeared in search results; it isn't the total demand for a phrase. [M03.L03]
- **Index** — a search engine's stored copy of the pages it has collected; search results come from the index, not from live websites. [M01.L03]
- **Indexing** — a search engine analysing a page and deciding whether to store it in its index; not every crawled page is indexed. [M01.L04]
- **Informational intent** — a search made to learn something, such as "how long does cold brew last". [M03.L01]
- **Inline style** — CSS in a `style` attribute on one element; a last resort. [M02.L08]
- **Internal and external links** — internal links point to another page on your own site; external links point to a different site. [M02.L05]
- **Internal stylesheet** — CSS in a `<style>` element in a page's `<head>`; it applies to that page only. [M02.L08]
- **Intrinsic size** — an image file's real width and height in pixels; compare it with the rendered size in DevTools. [M04.L04]
- **IP address** — the number that identifies a computer on the internet, in IPv4 (`192.0.2.10`) or IPv6 (`2001:db8::10`) format. [M02.L01]
- **Keyword** — a word or phrase that people search for. [M03.L02]
- **Keyword cannibalisation** — an industry term for two or more of your pages competing for the same searches with the same intent; Google's docs don't use it, and two pages in one set of results isn't a problem by itself. [M03.L05]
- **Keyword difficulty** — an SEO tool's estimate of how hard a phrase is to rank for. Each tool calculates it differently, and Google doesn't publish one. [M03.L03]
- **Keyword map** — a table that gives each topic one page (existing or planned), with its phrases, intent and page type. [M03.L05]
- **Keyword Planner** — a tool inside Google Ads showing rounded average monthly searches, plus competition and bids for advertisers. [M03.L03]
- **Keyword stuffing** — filling a page with keywords or numbers to manipulate rankings. [M01.L06]
- **Keyword variant** — a different form of the same search phrase, such as "cold brew ratio" and "cold brew coffee ratio"; use variants where they fit, not one per sentence. [M04.L03]
- **Knowledge panel** — a box about an entity (a business, person or place) shown for brand and entity searches. [M01.L05]
- **Landmark** — a part of a page that screen reader users can jump to directly, such as banner, navigation, main or contentinfo; created by elements like `<nav>` and `<main>`. [M02.L06]
- **`lang` attribute** — names a page's language for browsers and screen readers; Google detects language from the text instead. [M02.L03]
- **Lazy loading** — waiting to load an image or embed until the visitor scrolls near it, using `loading="lazy"`. [M02.L07]
- **Link spam** — links created mainly to manipulate rankings, including paid or exchanged links that aren't marked. [M01.L06]
- **Local pack** — a map with a few local businesses, shown for searches with local intent such as "near me" or a city name. [M01.L05]
- **Lock-in** — how hard it is to leave a platform and take your site with you. [M02.L02]
- **`<main>`** — the element that holds the content unique to a page; a page can have only one visible `<main>`. [M02.L06]
- **Long-tail phrase** — a specific search that few people make, with a clearer need; each gets little volume. An SEO term, not Google's. [M03.L02]
- **Manual action** — a penalty applied after a human reviewer at Google finds pages break the spam policies; shown in Search Console. [M01.L06]
- **Margin** — the space outside an element's border, between it and other elements. [M02.L09]
- **Marketing** — finding the right people, making them an offer they want and telling them about it where they already are (audience, offer, message, channel). [M01.L01]
- **Marketing mix (4 Ps)** — a classic framework: product, price, place and promotion. [M01.L01]
- **Measurement ID** — the ID of a GA4 web data stream, usually starting with `G-`. [M01.L08]
- **Media query** — a CSS condition, such as a minimum screen width, that applies rules only when it's true. [M02.L10]
- **Message** — what you say so your audience understands your offer and cares about it, e.g. a homepage headline. [M01.L01]
- **Meta description** — a short page summary in the HTML `<head>`; Google uses it for the snippet only sometimes. [M01.L05]
- **Meta keywords** — an old tag listing a page's keywords; Google doesn't use it for indexing or ranking. [M02.L03]
- **Mobile-first design** — writing a simple layout first, then adding styles for wider screens. [M02.L10]
- **Mobile-first indexing** — Google using the mobile version of a site's content for indexing and ranking. [M02.L10]
- **Nameserver** — the computer that holds a domain's official DNS records; NS records show which ones a domain uses. [M02.L01]
- **Navigational intent** — a search made to reach a specific site or page, such as "nila coffee contact". [M03.L01]
- **Nesting** — putting HTML elements inside each other; the last one opened must be the first one closed. [M02.L03]
- **`nosnippet` / `max-snippet` / `data-nosnippet`** — controls that stop or limit the text Google shows from a page or part of a page. [M01.L05]
- **Offer (value proposition)** — what the customer gets and why it's better than the alternatives; not just a list of features. [M01.L01]
- **Open Graph (OG) tags** — `<meta property="og:…">` tags that tell social and messaging apps which title, description and image to show when a page is shared. [M04.L06]
- **Ordered and unordered lists** — `<ol>` is for items where the order matters, such as steps; `<ul>` is for items where it doesn't, such as ingredients. [M02.L04]
- **Organic result** — a search result the engine chooses on its own; nobody can pay to be included or ranked there. [M01.L03]
- **Organic social / paid social** — your own unpaid posts on social platforms / ads on those platforms. [M01.L02]
- **Orphan page** — an SEO-tool term for a page with no internal links pointing to it; Google's rule is that every page you care about needs at least one. [M04.L05]
- **Owned media** — channels you control, such as your website, blog and email list. [M01.L02]
- **Padding** — the space inside an element's border, around its content. [M02.L09]
- **Page type** — the kind of page a result is, such as a guide, comparison list, product page, category page or location page. [M03.L01]
- **PageRank** — one of Google's fundamental algorithms, which uses links; just one of many ranking signals. [M01.L07]
- **Pagination** — splitting a long list across numbered pages, each with its own URL such as `?page=2`. [M04.L06]
- **Paid media** — attention you buy, such as search ads and social ads; it stops when the budget stops. [M01.L02]
- **Paid result (search ad)** — a result an advertiser pays for, usually per click, labelled as an ad (for example "Sponsored"); it disappears when the budget stops. [M01.L03]
- **Paid search (PPC)** — ads on search results pages, usually paid per click (PPC = pay per click). [M01.L02]
- **People also ask (related questions)** — an expandable list of related questions with short answers; not controllable. [M01.L05]
- **People-first content** — content made mainly to help people, not mainly to attract search visits; Google's helpful-content questions test for it. [M04.L03]
- **Permalink** — a page's permanent web address; in WordPress, set its pattern (ideally **Post name**) in Settings → Permalinks before the first post. [M05.L01]
- **Permanent redirect (301)** — an instruction that sends visitors and search engines from an old URL to a new one for good; needed whenever a live page's URL changes. [M04.L02]
- **Plugin (app)** — an add-on that gives a platform a new feature; WordPress says plugin, Shopify says app. [M02.L02]
- **Practice site** — a WordPress site for trying things safely, on your computer (Local), in your browser (Playground) or on hosting; only a hosted one is visible to Google. [M05.L01]
- **Primary intent** — the one main thing a page sets out to serve; this course gives each page one. [M03.L01]
- **Product variant** — one version of a product, such as a size or colour; if it has its own page it needs a real URL, not a `#`. [M04.L06]
- **Query** — the words someone types (or says) into a search engine. [M01.L03]
- **Quick win** — a target with a good chance and little effort, chosen for early progress. [M03.L04]
- **Ranking / serving** — choosing and ordering the most relevant indexed pages for a search, and showing them. [M01.L04]
- **Ranking factor (signal)** — any information Google's ranking systems use to order results; the full list and weights aren't public. [M01.L07]
- **Ranking system / core ranking systems** — the automated systems that order results; the core ones are the underlying technology behind search results. [M01.L07]
- **Realtime report** — the GA4 report showing activity in the last 30 minutes; used to confirm the tag works. [M01.L08]
- **Reconsideration request** — the review you ask for in Search Console after fixing every issue in a manual action. [M01.L06]
- **Redirect** — a rule that sends visitors and search engines from an old URL to a new one. [M02.L02]
- **Referral traffic** — visits from a non-ad link on another website or app (GA4: Referral). [M01.L02]
- **Registrar** — the company you register and renew a domain through. [M02.L01]
- **Registry** — the organisation that keeps the master database for one domain ending, such as `.com`. [M02.L01]
- **`rel` attribute** — describes a link's relationship to its destination: `sponsored` for paid links, `ugc` for user-posted links, `nofollow` for links you don't trust. Most links need none. [M02.L05]
- **`rel="sponsored"`** — a link attribute that marks an ad or paid placement, so the link stays within Google's policies. [M01.L06]
- **`rem`** — a CSS unit based on the root font size, usually 16px; text set in `rem` respects readers' font settings. [M02.L09]
- **Rendered size** — how big an image is shown on the page; a file much bigger than this wastes download time. [M04.L04]
- **Rendering** — running a page's code (including JavaScript) to build the page a visitor sees; Google renders with a recent version of Chrome. [M01.L04]
- **Rented channel** — a channel you use but don't control, such as a social media profile; the platform sets the rules and the reach. [M01.L02]
- **Request / response** — a browser or crawler asks a server for a URL (request); the server answers with a status code and, if it worked, the page's code (response). [M01.L04]
- **Responsive design** — serving the same HTML on every device, with CSS adjusting the layout; Google's recommended pattern. [M02.L10]
- **Results page (SERP)** — the page a search engine shows after a query; SERP stands for "search engine results page". [M01.L03]
- **Results-page overlap (SERP overlap)** — how many of the same pages appear in the top results for two phrases; a lot of overlap suggests one topic. [M03.L05]
- **Rich result** — a search result with extras such as star ratings, prices or cooking times; typically relies on structured data. [M01.L05]
- **`robots.txt`** — a file at the top of a site telling crawlers which URLs not to request; on some platforms you can't edit it. [M02.L02]
- **Scaled content abuse** — many pages made mainly to manipulate rankings, with little value, however they were created. [M01.L06]
- **Search competitor** — any site that ranks for the searches you want, which may be a blog, video or directory rather than a similar business. [M01.L05]
- **Search Console property** — a website, or part of one, that you've proved you control in Search Console. [M01.L08]
- **Search engine** — a service such as Google or Bing that collects web pages and shows the most useful ones for each query. [M01.L03]
- **Search intent** — what someone is trying to get done when they search. [M03.L01]
- **Search operator** — a special command typed into the search box that narrows the results, such as `site:` or quotes. [M01.L03]
- **Search volume** — roughly how often a phrase is searched each month; an estimate, and not the same as visits to your site. [M03.L03]
- **Seasonality** — a pattern of search interest that repeats at the same time each year. [M03.L03]
- **Seed term** — a short, broad starting point for keyword research, taken from your audience, your offer or customers' words. An SEO term, not Google's. [M03.L02]
- **Selector** — the part of a CSS rule that picks which elements to style. [M02.L08]
- **Self-hosted CMS** — a CMS that runs on hosting you choose, such as WordPress from wordpress.org; you handle updates, backups and security. [M02.L02]
- **Semantic HTML** — using elements that say what content is, such as `<nav>` or `<article>`, instead of generic `<div>`s. Good for accessibility, but Google's public comments say it isn't a ranking factor. [M02.L06]
- **SEO (search engine optimisation)** — helping search engines understand your content and helping people find your site and decide to visit it from search results. [M01.L03]
- **SERP feature** — any part of a results page beyond a plain text result, such as a featured snippet, local pack, image strip or ad. [M01.L05]
- **Share preview** — the card an app shows for a shared link, built from the page's Open Graph tags or the app's own guess. [M04.L06]
- **Shared hosting** — hosting where many sites use one server; low cost, and not an SEO problem by itself unless the server is slow or fails. [M02.L01]
- **`site:` operator** — `site:example.com` shows results from one site only; a quick sample of what the engine has indexed, not an exact count. [M01.L03]
- **Sitelinks** — extra links to pages on the same site under a result; automated by Google. [M01.L05]
- **Sitemap (XML sitemap)** — a file listing the URLs you want search engines to find, often at `/sitemap.xml` (WordPress: `/wp-sitemap.xml`). [M01.L04]
- **Skipped heading level** — a jump down of more than one level, such as `<h2>` straight to `<h4>`. Going back up to start a new section is fine. [M02.L04]
- **Slug** — the last part of a page's URL, such as `cold-brew-guide`; Shopify calls it a handle. [M02.L02]
- **Snippet** — the description under a result's title; mostly taken from page content. [M01.L05]
- **Soft 404** — a page that says "not found" (or is nearly empty) but returns status 200 instead of 404. [M01.L04]
- **Spam policies** — Google's published list of practices that can get pages ranked lower or removed from results. [M01.L06]
- **Spam update / core update** — changes to Google's systems, listed on the Search Status Dashboard; spam updates target spam, core updates are broad. [M01.L06]
- **Specificity** — the weight a browser gives a selector when rules conflict: ID beats class, and class beats element. [M02.L08]
- **Status code** — a three-digit number in a server's response: 200 OK, 301/302 moved, 404 not found, 500-range server error. [M01.L04]
- **Stretch target** — a valuable but harder target that you work towards over time. [M03.L04]
- **Structured data** — code (usually JSON-LD) that describes a page's content to search engines in a standard format; rich results typically rely on it (Module 12). [M01.L05]
- **Synced pattern** — a saved group of blocks that stays the same everywhere it's used; editing it once updates every page. [M05.L03]
- **Tag (HTML)** — the label that opens or closes an element, such as `<p>` and `</p>`. [M02.L03]
- **Tag (WordPress)** — an optional label shared by several posts across categories; each tag in use gets its own archive page. Not the same as an HTML tag. [M05.L02]
- **Tap target** — a link or button someone taps; W3C's minimum is 24 by 24 CSS pixels, and web.dev recommends around 48. [M02.L10]
- **Target audience** — the specific group of people a site or business is for, narrow enough to picture one real person. [M01.L01]
- **`target="_blank"`** — opens a link in a new tab; use it rarely, and say so in the link. [M02.L05]
- **Target phrase** — a phrase you've chosen to work on, after checking its intent, value, chance and effort. [M03.L04]
- **Text result** — Google's name for an ordinary search result: attribution, title link, snippet. [M01.L05]
- **Theme (template)** — the design files that control how a CMS's pages look. [M02.L02]
- **Thin archive** — a category or tag archive with so few posts, or so little else, that it adds nothing beyond the posts themselves (course term). [M05.L02]
- **`<title>` element** — the page's name in the head, shown in the browser tab and used as a main source for the title link. [M02.L03]
- **Title link** — the clickable headline of a result; generated automatically from the `<title>`, headings and other text. [M01.L05]
- **Title rewrite** — when Google's title link differs from a page's `<title>`, because Google built it from headings, other page text or links. [M04.L01]
- **Topic (keyword cluster)** — a group of phrases with the same intent that one page can fully answer. [M03.L05]
- **Transactional intent** — a search made to do something now, such as buy or book. [M03.L01]
- **TTL (time to live)** — how long, in seconds, a DNS answer may be remembered before it is looked up again. [M02.L01]
- **Types of SEO** — on-page (the content and code of the page itself), off-page (links, mentions and reviews from elsewhere) and technical (whether search engines can find, read and store the site). [M01.L03]
- **URL parameter** — text after a `?` in a URL, such as `?p=123` or `?ref=home`, in `key=value` pairs; use as few as you can. [M04.L02]
- **URL-prefix property** — a Search Console property covering only URLs that start with one exact prefix; several verification methods. [M01.L08]
- **User agent** — the name a browser or crawler sends with each request (e.g. Googlebot); it can be faked, so verify crawlers by IP. [M01.L04]
- **Validator** — a free tool that checks code against the HTML rules, such as the W3C Nu HTML Checker. [M02.L03]
- **View Source** — the browser view (Ctrl+U / Cmd+Option+U) that shows the HTML the server sent, before JavaScript runs. [M01.L04]
- **Viewport** — the visible area of a page in a browser; the viewport meta tag makes it match a phone's screen. [M02.L10]
- **Void element** — an element with one tag and no closing tag, because it can't contain content, such as `<meta>` or `<img>`. [M02.L03]
- **Watch page** — Google's term for a page whose main purpose is to show one video; needed for a page's video to appear in video results. [M02.L07]
- **WCAG** — Web Content Accessibility Guidelines, the W3C's accessibility standard. [M02.L09]
- **Web data stream** — the connection that sends data from a website into a GA4 property. [M01.L08]
- **Web server** — the computer, the software, or both together, that stores a website and sends its files when asked. [M02.L01]
- **WebP and AVIF** — newer image formats that usually make smaller files than JPEG or PNG at the same quality; Google Search supports both. [M04.L04]
- **Website builder** — a hosted service that bundles an editor, templates and hosting, such as Wix or Squarespace. [M02.L02]
- **White hat SEO** — improving a site for people, inside the search engines' rules. Industry slang, not Google's term. [M01.L06]
- **WordPress Playground** — WordPress running inside a browser tab, with no server or account; private, and kept only until browser storage is cleared unless you export a ZIP. [M05.L01]
- **WXR file** — WordPress's XML export of content (posts, pages, comments), made in Tools → Export; it doesn't include themes, plugins or settings. [M05.L01]
- **YMYL (Your Money or Your Life)** — topics that could significantly affect health, finances, safety or society; Google gives E-E-A-T more weight here. [M01.L07]
